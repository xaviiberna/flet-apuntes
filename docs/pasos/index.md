# Tutorial: de «Hola mundo» a la app completa

Cada archivo es **completo y ejecutable** y añade una novedad respecto al anterior. Copia el código a mano al menos en los primeros pasos: te acostumbra a Flet.

| Paso | Tema | Concepto principal |
|---|---|---|
| [1](paso1.md) | Hola mundo | `main(page)`, `page.add`, `ft.run` |
| [2](paso2.md) | Página y estilo de texto | propiedades y enumeraciones |
| [3](paso3.md) | TextField y Button | controles de entrada |
| [4](paso4.md) | Eventos | `on_click` y `page.update()` |
| [5](paso5.md) | Layouts y Checkbox | `Row`, `Column`, `expand` |
| [6](paso6.md) | Borrar tareas | `IconButton` y `lambda` |
| [7](paso7.md) | Validación | `error`, `on_submit`, `return` |
| [8](paso8.md) | App final | `on_change` y estado derivado |
| [9](paso9.md) | Clases | `@ft.control`, callbacks, `before_update` |

!!! tip "Cómo estudiar cada paso"
    1. Lee el **objetivo**. 2. Mira el **código**. 3. Lee la tabla **«qué hace cada línea»**. 4. Haz **«Prueba tú»**.
